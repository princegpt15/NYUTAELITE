# SEO Reports

This directory stores weekly GSC rank monitoring reports generated by:

```
npm run seo:gsc
# or
node scripts/gsc-rank-monitor.mjs
```

## Files

- `gsc-weekly-YYYY-MM-DD.txt` — Weekly Google Search Console performance report
  - Top 25 ranking queries
  - Per-page clicks / impressions / CTR / position
  - Makhana-specific query breakdown
  - Mobile vs Desktop split
  - Learn article performance

## Setup

See `.env.example` for the `GOOGLE_SERVICE_ACCOUNT_JSON` setup instructions.

## Scheduling (Weekly Automation)

Add to your CI/CD or run locally every Monday:

```bash
# Manually (local)
node scripts/gsc-rank-monitor.mjs

# Cloudflare Workers Cron (cloudflare.toml)
# [triggers]
# crons = ["0 6 * * 1"]  # Every Monday 6 AM UTC
```

Reports in this directory are gitignored and are local-only.
